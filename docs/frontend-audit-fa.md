# گزارش وضعیت فرانت‌اند PharmArt

> دامنه: فقط فرانت‌اند (React + Vite). بک‌اند در ریپوی جداگانه است و در این مرحله
> در دسترس نبود؛ بنابراین همهٔ موارد با شواهد کد و بررسی ایستا (typecheck، lint،
> build، grep) ثبت شده‌اند، نه با تست قرارداد API.

## خلاصه

نسخهٔ اولیه یک SPA تک‌فایلی با داده‌های نمونه، بدون تست، CI، مدیریت خطا و با
مسیرهای API هاردکدشده بود. در این پاس، مسائل بحرانی زیر رفع و بقیه مستند شد.

## اعداد قابل استناد

- `tsc --noEmit` با `strict` + `noUnusedLocals/Parameters`: **۰ خطا**
- `eslint .`: **۰ خطا، ۰ warning**
- تست واحد: **۲۵ تست در ۵ فایل** (client، auth-token، format، errors، ErrorBoundary)
- `npm audit --omit=dev`: **۰ آسیب‌پذیری**
- build: main chunk ≈ **۳۰۹ kB (۹۴ kB gzip)**، CSS ≈ **۷۸ kB (۱۳ kB gzip)**؛
  صفحات سنگین lazy هستند (`CustomerStorefront`, `InventoryManager`, `AdminUsersPage`, …)
- فونت: `public/fonts/vazirmatn-variable.woff2` (۱۰۹ kB) + `OFL`، self-hosted

## تصمیم‌های مهم

- **پول:** همهٔ مبالغ از `lib/format.ts` عبور می‌کنند. برچسب واحد در `config.ts`
  (`MONEY_UNIT_LABEL`) است و با `VITE_MONEY_UNIT_LABEL=ریال` قابل تغییر است.
  پیش‌فرض «تومان» است چون ویترین، ورودی تخفیف و کمپین‌ها قبلاً تومان بودند.
  **قبل از قرارداد، واحد ذخیره‌شده در بک‌اند باید قطعی شود.**
- **احراز هویت:** توکن فعلاً در `localStorage` است تا با API فعلی سازگار بماند؛
  مسیر مهاجرت به کوکی `HttpOnly` در `docs/adr/0001-api-client-and-auth.md` آمده است.
- **مجوزدهی:** کنترل دسترسی در UI فقط UX است. سرور باید برای هر endpoint نقش و
  مالکیت داروخانه را مستقل بررسی کند؛ این مورد در دامنهٔ این ریپو نیست.

## ریسک‌های باقی‌مانده (شفاف)

1. تست قرارداد با بک‌اند انجام نشده؛ شکل پاسخ‌ها از `src/api/*.ts` استنتاج شده است.
2. توکن در `localStorage` → در صورت XSS قابل خواندن است؛ مهاجرت به کوکی امن لازم است.
3. Router واقعی وجود ندارد؛ ناوبری با state است و deep-link فقط برای صفحهٔ عمومی/کاتالوگ.
4. پرداخت امانی واقعی نیست (فقط شبیه‌ساز با `DemoNotice`)؛ درگاه پرداخت باید جدا افزوده شود.
5. پوشش تست کم است (منطق پایه، نه E2E)؛ برای قرارداد سازمانی حداقل تست E2E مسیر خرید لازم است.
6. درایور موبایل: منوی کشویی دسکتاپ/موبایل اصلاح شد، اما تست دسترسی‌پذیری با screen reader انجام نشده.
7. به‌روزرسانی خودکار داده‌ها در تبادل ۲۰ ثانیه‌ای است؛ برای بار بالا بهتر است WebSocket یا
   polling با backoff و visibility-aware جایگزین شود.

```bash
npm ci

npm run build
npm run audit:prod
```

توصیف می‌کند؛ این فایل وضعیت فعلی فرانت‌اند را ثبت می‌کند.
